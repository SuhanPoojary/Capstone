### Using the Resource Tokens
All dimensions, colors, and strings are centralized for easy maintenance:

```xml
<!-- Use from layout files -->
android:layout_margin="@dimen/medready_hero_padding"
android:background="@color/sr_accent_navy"
android:text="@string/medready_hero_title"
```

